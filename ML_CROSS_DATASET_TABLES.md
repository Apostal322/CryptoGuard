## Decision gates

| Gate | Status | Evidence |
|---|---|---|
| 1 Data integrity | pass | pinned size/MD5/SHA-256; 0 malformed rows; publisher counts reproduced |
| 2 Event identity | partial | transactions, attempts (victim, lookalike, tx) and Poison-Hunter victim-events are distinct; the archive has no log index (895,966 repeated transfer keys) and no campaign identifier |
| 3 Label validity | fail | archive categories are the source's heuristic labels (lookalike rule, thresholds), not independent review of attempts; payoffs are confirmed outcomes, not attempt labels |
| 4 Temporal integrity | partial | block-level ordering only (no transaction index or timestamps in the archive): same-block pairs are 'order unknown'; fixture-based features keep exact cutoffs |
| 5 Independent evaluation | fail | no verified negatives in any source; not listed or not paid does not mean benign |
| 6 Leakage control | partial | campaign grouping and grouped temporal splits exist, but there are no trainable labels to split |
| 7 Baseline comparability | fail | the archive holds only poisoning-related transfers, not the wallet histories the deterministic detector needs, so both cannot run on the same observations |
| 8 Operational usefulness | fail | alert volume on ordinary wallets is known only from 27 recorded wallet-days; 1,635 payoff-linked attempts are retrospective, not prospective |

Reconciliation runtime 5.7 s, peak RSS 339 MiB.
